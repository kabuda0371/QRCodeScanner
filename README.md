# 二维码识别助手（QR Scanner）

浏览器扩展（Chrome / Edge）：右键网页图片一键识别二维码，专治**公众号文章、网申页面**里二维码无法扫码的问题。全程本地识别，零上传。

## 功能

| 操作 | 效果 |
| --- | --- |
| 二维码图片上**右键** →「🔍 识别此图片中的二维码」 | 弹出结果卡片：显示内容，一键**复制**或**打开链接** |
| 页面上**右键** →「✂️ 框选区域识别二维码」 | 鼠标拖框识别任意屏幕区域（视频、海报角落、截图里的码都能扫） |
| 页面空白处**右键** →「🔍 扫描本页所有二维码」 | 自动扫出整页所有二维码（含 CSS 背景图），列表展示 |
| 点击工具栏图标 | 等同「扫描本页所有二维码」 |

其他特性：

- 识别过程**实时显示步骤**，可随时取消；点击复制/跳转后消息自动清空
- 自动识别类型：链接、微信、WiFi 配置、电话、邮箱、名片、普通文本
- 三重识别引擎（浏览器原生 + jsQR + zxing-cpp），旋转、反色、彩色、微型、海报角落小码都能识别
- 微信弹窗二维码（图片地址由 JS 动态填充）会等待加载完成后识别
- 识别失败自动换方案：直接解码 → 后台抓原图 → 屏幕截图，全程超时保护

## 怎么用

### 安装

1. 下载本仓库（Code → Download ZIP）并解压
2. **Chrome**：地址栏输入 `chrome://extensions` → 打开右上角「开发者模式」→「加载已解压的扩展程序」→ 选择本文件夹
3. **Edge**：地址栏输入 `edge://extensions` → 打开左侧「开发人员模式」→「加载解压缩的扩展」→ 选择本文件夹
4. 刷新已打开的网页即可生效

> 升级新版：扩展管理页移除旧版 → 重新加载本文件夹。
> 360 极速、QQ 浏览器等 Chromium 内核浏览器同样适用。

### 使用

- 二维码图片上右键 →「🔍 识别此图片中的二维码」
- 自动识别失败时：右键 →「✂️ 框选区域识别二维码」，把二维码连同白边一起框进去
- 想知道装没装好：打开 `test/test.html`，页面显示「✅ 自动验证通过」即正常（若右键菜单不出现，去扩展详情页开启「允许访问文件网址」后刷新）

### 权限说明

安装时提示的「读取所有网站数据」仅用于识别你右键选中的图片（后台抓原图、屏幕截图）；所有识别都在本地完成，不收集、不上传任何数据。
